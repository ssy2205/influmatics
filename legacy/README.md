# Legacy Scripts

This folder preserves the original prototype scripts exactly as project reference material.

Current files include:

- `auto_pipeline.sh`: ONT FASTQ to Medaka consensus shell pipeline
- `blast_version2.py`: online NCBI BLAST prototype
- `influenza_a_analysis.py`: monolithic integrated analysis prototype
- `phylogenetic_tree_visualization_*.R`: hard-coded R tree visualization scripts

New development should happen in the `influmatics/` package. Legacy code can be migrated module by module through focused issues and pull requests.
