? 이 프로그램이 뭐예요?

독감 바이러스는 해마다 조금씩 모습을 바꿉니다. 그래서 작년 백신이 올해는 잘 안 들을 수 있어요. 이 프로그램은 바이러스의 유전자 글자(서열)를 받아서:

  • 서열이 분석하기에 깨끗한지 검사하고(QC),
  • 기준 바이러스와 비교해 어디가 바뀌었는지(돌연변이) 찾고,
  • 그 변화가 면역을 피하는 자리(항원 부위)나 약이 안 듣게 만드는 자리(내성 마커)인지 알려줍니다.
💡비유 — 바이러스 사진 두 장을 겹쳐 놓고 “여기 점이 새로 생겼네!”를 자동으로 찾아 표시해 주는 ‘틀린그림찾기 도우미’라고 생각하면 됩니다.

0 시작 전 준비물

필요한 것설명
맥(Mac) 컴퓨터이 설명서는 Mac 기준이에요.
터미널(Terminal)명령어를 적는 검은 창. ⌘ Cmd + 스페이스 → “터미널” 검색.
분석할 서열 파일끝이 .fasta 인 텍스트 파일. 없으면 프로그램에 들어있는 예제 파일로 연습할 수 있어요.
💡걱정 마세요 — 설치는 딱 한 번만 하면 됩니다. 그 다음부터는 명령어 한 줄이면 끝이에요.

1 터미널 열고 폴더로 이동 복사 → 붙여넣기

터미널을 열고 아래 줄을 그대로 복사해서 붙여넣은 뒤 Enter 를 누르세요. 프로그램이 들어있는 폴더로 들어가는 명령이에요.

# 프로그램 폴더로 이동
cd /Users/shiftyellow/Documents/project-local/influmatics_project/influmatics_code
💡 글자가 아무것도 안 나와도 정상이에요. 오류 메시지만 안 뜨면 성공입니다.

2 최초 1회 설치 딱 한 번만

아래 두 줄을 한 줄씩 붙여넣고 Enter 하세요. 첫 줄은 프로그램 전용 작업공간을 켜고, 둘째 줄은 웹 화면 기능을 설치합니다.

# 1) 전용 작업공간 켜기
source .venv/bin/activate
# 2) 웹 화면 기능 설치 (처음 한 번만, 1~2분 걸릴 수 있어요)
pip install -e ".[web]"
✅ 줄 맨 앞에 (.venv) 표시가 보이면 작업공간이 잘 켜진 거예요.
⚠️두 번째부터는 설치 줄(pip install ...)은 다시 안 해도 됩니다. source .venv/bin/activate 만 해주면 돼요.

3 웹 화면 켜기 명령어 한 줄

이제 아래 한 줄만 입력하면 인터넷 브라우저가 자동으로 열리면서 프로그램 화면이 나타납니다.

influmatics web

브라우저가 자동으로 안 열리면, 터미널에 보이는 주소 http://localhost:8501 를 복사해서 브라우저 주소창에 붙여넣으세요.

4 QC 탭 · 서열 품질 검사 분석 전 건강검진

QC는 “Quality Check(품질 검사)”의 줄임말이에요. 서열이 너무 짧거나, 알 수 없는 글자가 섞여 있지 않은지 미리 확인합니다.

  1. QC 탭을 누릅니다.
  2. “FASTA input” 칸에 .fasta 파일을 끌어다 놓습니다.
  3. 표가 자동으로 나타납니다. 길이·이상한 글자 개수 등이 보여요.
  4. pass_qc 칸이 True 이면 합격, False 이면 주의가 필요한 서열이에요.
  5. “Download QC TSV” 버튼으로 결과표를 저장할 수 있습니다.
🧪연습용 파일 — 프로그램 안에 예제 서열이 있어요. 파일 올릴 때 이 경로의 파일을 고르면 됩니다:
data/references/FJ966974.1_H1N1pdm09_HA.fasta (2009 신종플루 H1N1)
data/references/A_Aichi_1968_H3N2_HA.fasta (1968 홍콩독감 H3N2)

5 스캔 탭 · 변이 찾기 진짜 분석

Antigenic / Resistance scan 탭은 “이 바이러스의 변이가 면역을 피하는 자리인지, 약이 안 듣게 하는 자리인지” 자동으로 표시해 줍니다.

이 탭은 아미노산 변이 표(TSV 파일)를 받아요. 이 표는 아래 명령어 한 줄로 만들 수 있어요. (인터넷 연결 필요 — 기준 정보를 잠깐 내려받습니다.)

# 서열에서 아미노산 변이표를 자동으로 만들기 (예: H1N1)
influmatics clade \
  --input-fasta data/references/FJ966974.1_H1N1pdm09_HA.fasta \
  --dataset nextstrain/flu/h1n1pdm/ha \
  --outdir results/nextclade \
  --out results/clades.tsv \
  --aa-out results/aa_mutations.tsv

그러면 results/aa_mutations.tsv 파일이 생깁니다. 이제 웹 화면에서:

  1. Antigenic / Resistance scan 탭을 누릅니다.
  2. 방금 만든 aa_mutations.tsv 를 “AA mutation TSV” 칸에 올립니다.
  3. “Marker table”에서 비교할 기준표를 고릅니다:
    • H1N1 antigenic sites — 신종플루 면역 회피 자리
    • H3N2 antigenic sites — 홍콩독감 계열 면역 회피 자리
    • Antiviral resistance markers — 약 내성 자리
  4. 일치하는 변이가 표로 나오고, “Download hits TSV”로 저장할 수 있어요.
⚠️ 올리는 표는 반드시 아미노산 표여야 해요(coordinate_space=aa). 위 명령어로 만든 파일은 자동으로 맞춰져 있으니 그대로 쓰면 됩니다.

📖 결과 읽는 법

항원 부위(antigenic site) 결과 — 표에 줄이 나오면, 그 변이가 면역을 피하는 자리에서 일어났다는 뜻이에요.

mutationpositionsite뜻
N145K145A145번 자리(부위 A)가 바뀜 → 면역 회피 가능성
K156N156Sb156번 자리(부위 Sb)가 바뀜

내성 마커(resistance) 결과 — 줄이 나오면, 그 변이가 약 효과를 떨어뜨릴 수 있는 알려진 자리예요.

mutationdrug_class뜻
H275Yneuraminidase_inhibitor타미플루 계열 약 내성 대표 변이
S31Nadamantane아만타딘 계열 약 내성 변이
💡 표가 비어 있으면 “해당 위험 자리에서는 변이가 없다”는 뜻이라 오히려 좋은 신호일 수 있어요. (예: HA 유전자만 넣으면 약 내성 자리는 NA/M2 유전자에 있어서 결과가 비어 있는 게 정상입니다.)

⏻ 프로그램 끄는 법

웹 화면을 다 썼으면, 프로그램을 켰던 터미널 창을 클릭하고 Control + C 를 누르세요. 그러면 멈춥니다. 브라우저 탭은 그냥 닫으면 돼요.

🛟 문제가 생겼을 때

❌“command not found: influmatics”
작업공간이 안 켜졌어요. source .venv/bin/activate 를 먼저 실행하세요(줄 앞에 (.venv) 가 보여야 함).
❌“attempted relative import …” 같은 빨간 글씨
최신 버전에서 고쳐졌습니다. influmatics web 으로 켜는 것을 권장하고, 만약 직접 streamlit run 으로 켰다면 프로그램 폴더 안에서 실행했는지 확인하세요.
❌“Port 8501 is already in use”(포트 사용 중)
이미 한 번 켜져 있어요. 다른 번호로 켜면 됩니다:
influmatics web --port 8600
❌브라우저가 자동으로 안 열려요
터미널에 적힌 주소(예: http://localhost:8501)를 복사해서 브라우저 주소창에 직접 붙여넣으세요.

📚 어려운 단어 사전

FASTA
유전자 글자(A·C·G·T)를 적어놓은 텍스트 파일 형식. 첫 줄에 > 로 이름을 적어요.
서열(sequence)
바이러스 유전자를 이루는 글자들의 줄. 바이러스의 ‘설계도 글자’예요.
QC
Quality Check. 서열이 분석하기에 깨끗한지 미리 확인하는 단계.
돌연변이(mutation)
기준 바이러스와 비교했을 때 바뀐 글자 또는 아미노산. 예: N145K = 145번이 N→K로 바뀜.
아미노산(amino acid)
단백질을 이루는 기본 조각. 유전자 글자 3개가 아미노산 1개를 정해요.
항원 부위(antigenic site)
우리 몸 면역(항체)이 알아보는 바이러스 표면의 특정 위치. 여기가 바뀌면 면역을 피할 수 있어요.
내성 마커(resistance marker)
이게 바뀌면 특정 약이 잘 안 듣게 되는, 알려진 변이 자리.
clade(클레이드)
비슷한 바이러스끼리 묶은 ‘가족 이름’. 어느 유행 계통인지 알려줘요.
Nextclade
서열을 기준과 비교해 clade와 변이를 자동으로 찾아주는 도구.
더 자세한(전문가용) 설명은 docs/usage_guide.html 를 참고하세요.
