고등학생도 따라할 수 있는 인플루엔자 데이터 수집법

딥러닝 모델을 학습하려면 서열 FASTA, metadata, 라벨 TSV가 필요합니다. 처음에는 NCBI Virus에서 공개 HA 서열과 metadata를 받고, 라벨은 논문 부록이나 WHO/CDC 보고서를 참고해 작게 시작하는 것이 가장 안전합니다.

1. 목표 정하기H3N2 HA1부터 시작합니다.
2. FASTA 받기NCBI Virus에서 protein 또는 CDS FASTA를 받습니다.
3. Metadata 받기같은 검색 결과에서 CSV도 받습니다.
4. 라벨 만들기항원성 좌표/HI/vaccine label을 정리합니다.
5. 코드에 넣기data/private/에 저장하고 검증합니다.

1. 바로 결론

처음 데이터 수집은 NCBI Virus로 시작하세요. 공개 데이터이고, FASTA와 metadata CSV를 같은 검색 결과에서 받을 수 있어 학생 프로젝트에 가장 다루기 쉽습니다.

1순위 사이트 NCBI Virus 에서 H3N2 HA 단백질 또는 CDS 서열과 metadata CSV를 받습니다.
2순위 참고 사이트 WHO vaccine recommendations 와 CDC 설명 자료로 vaccine strain과 항원성 배경을 확인합니다.
주의할 사이트 GISAID 는 최신 데이터가 많지만 계정, 약관, 재배포 제한이 있어 처음에는 필수로 쓰지 않습니다.

2. 어떤 사이트에서 무엇을 받을까

사이트 받을 데이터 처음 사용자 추천도 주의점
NCBI Virus Protein FASTA, CDS FASTA, nucleotide FASTA, Results Table CSV metadata 가장 추천 필터를 너무 넓게 잡으면 파일이 커집니다. H3N2 + HA + human + 연도 범위로 좁히세요.
GISAID EpiFlu 최신 influenza 서열과 metadata 지도교사/연구실 도움 있을 때 약관상 데이터를 외부에 재배포하면 안 됩니다. 저장소에 올리지 마세요.
Nextstrain seasonal-flu 계통수 분석 workflow, 예시 데이터, influenza 분석 설정 분석 흐름 참고용 우리 모델 학습용 원본 FASTA/label을 바로 주는 사이트라기보다 workflow 참고용입니다.
WHO vaccine recommendations 계절별 vaccine strain 추천 문서 라벨/배경 정리용 FASTA 다운로드 사이트가 아닙니다. vaccine match label을 만들 때 참고합니다.
CDC influenza viruses 항원성, drift/shift, sequencing 설명 개념 이해용 모델 입력 파일보다 배경 설명에 가깝습니다.
논문 supplementary data 항원성 좌표, HI assay table, strain metadata 라벨 확보용 라이선스와 파일 형식이 논문마다 다릅니다. 출처를 꼭 기록하세요.

3. 처음 목표 설정

처음부터 모든 influenza subtype을 모으지 마세요. 학습 목표가 너무 커지면 정리하기 어렵습니다. 이 프로젝트에서는 아래처럼 시작하는 것을 추천합니다.

추천 첫 목표: A/H3N2, human host, HA 또는 HA1 단백질 서열, 2015년 이후 자료, 항원성 좌표나 vaccine label 예측.

처음 검색 조건

  • Virus: Influenza A virus
  • Subtype: H3N2
  • Host: Homo sapiens 또는 human
  • Gene/segment/protein: HA 또는 hemagglutinin
  • Collection year: 예를 들어 2015-2026
  • Sequence type: 처음에는 protein FASTA가 편합니다.

4. NCBI Virus에서 FASTA와 metadata 받기

NCBI Virus 도움말은 검색, metadata filter, custom report, 다양한 format export를 지원한다고 설명합니다. 다운로드 메뉴에서는 nucleotide/protein/CDS FASTA와 metadata가 들어 있는 Results Table CSV를 받을 수 있습니다.

4-1. NCBI Virus 접속

  1. NCBI Virus에 들어갑니다.
  2. 검색창에서 Influenza A virus를 검색합니다.
  3. 결과 화면에서 왼쪽 filter를 사용합니다.

4-2. 필터 설정

필터 고를 값 이유
Host Human 또는 Homo sapiens 사람에서 유행하는 계절성 influenza를 보려는 목적입니다.
Subtype H3N2 첫 모델 목표를 H3N2 HA1로 좁힙니다.
Protein / Gene HA, hemagglutinin 항원성 예측의 핵심 입력입니다.
Collection date 2015년 이후부터 시작 처음에는 최근 자료가 정리하기 쉽습니다.
Completeness complete 또는 full-length 우선 짧거나 끊긴 서열은 모델 입력 품질을 낮출 수 있습니다.

4-3. FASTA 다운로드

  1. 결과 표에서 Protein 탭을 선택합니다.
  2. Download All Results 또는 선택한 row만 Download Results를 누릅니다.
  3. data type으로 Protein FASTA를 고릅니다.
  4. 처음에는 너무 많이 받지 말고 100-500개 정도로 시작합니다.
  5. 파일명을 h3n2_ha_protein_raw.fasta로 저장합니다.

4-4. Metadata CSV 다운로드

  1. 같은 검색 결과 화면에서 다시 다운로드 메뉴를 엽니다.
  2. Results Table contents in CSV를 선택합니다.
  3. 파일명을 h3n2_ha_metadata_raw.csv로 저장합니다.
왜 FASTA와 CSV를 둘 다 받나요? FASTA는 모델 입력 서열이고, CSV는 각 서열의 연도, 국가, host, strain 이름 같은 설명표입니다. 둘은 accession 또는 strain 이름으로 나중에 연결해야 합니다.

5. GISAID는 언제 사용할까

GISAID는 influenza 최신 데이터가 많지만, 계정이 필요하고 데이터 공유 제한이 있습니다. GISAID 등록 페이지는 사용자에게 Database Access Agreement 동의, 기여자 인정, GISAID 밖으로 데이터 재배포 금지 등을 안내합니다.

중요: GISAID에서 받은 FASTA나 metadata는 GitHub, 공개 저장소, 발표자료 부록, 공유 폴더에 올리지 마세요. 이 프로젝트에서는 data/private/ 또는 저장소 밖에 둡니다.

GISAID를 써도 되는 경우

  • 지도교사나 연구실에서 계정과 사용 범위를 확인해준 경우
  • 논문/발표에서 기여자 acknowledgement를 제대로 정리할 수 있는 경우
  • 데이터를 외부에 재배포하지 않는 로컬 분석만 할 경우

6. 라벨은 어디서 모을까

딥러닝 학습에서 가장 어려운 부분은 FASTA보다 라벨입니다. 항원성 예측 모델은 “정답”이 있어야 학습됩니다.

라벨 종류 어디서 찾나 처음 만들 파일
Antigenic map coordinate 논문 supplementary data, 항원 지도 연구 데이터 h3n2_antigenic_coordinates.tsv
HI assay table 논문 부록, WHO collaborating center 보고서, 공개 serology 자료 h3n2_hi_table.tsv
Vaccine strain match WHO vaccine composition recommendations, CDC antigenic characterization 설명 h3n2_vaccine_match_labels.tsv
Proxy label 우리 코드가 만든 항원 부위 mutation count h3n2_proxy_labels.tsv
학생 프로젝트 팁: 처음부터 완벽한 항원성 좌표를 찾기 어렵다면, 작은 논문 dataset 하나를 골라 strain 이름과 좌표를 손으로 TSV로 정리해도 됩니다. row가 적어도 파이프라인 연습에는 충분합니다.

7. 저장 폴더와 파일명

원본 데이터와 정리한 데이터를 분리하면 실수를 줄일 수 있습니다. 아래 폴더 구조를 그대로 쓰면 됩니다.

폴더 만들기
mkdir -p data/private/raw \
  data/private/processed \
  data/private/labels \
  analysis_results/influenza_protein_dl
파일 저장 위치 설명
h3n2_ha_protein_raw.fasta data/private/raw/ NCBI에서 받은 원본 protein FASTA
h3n2_ha_metadata_raw.csv data/private/raw/ NCBI에서 받은 원본 metadata CSV
h3n2_metadata.tsv data/private/processed/ 모델 입력에 맞게 정리한 metadata
h3n2_antigenic_labels.tsv data/private/labels/ 직접 정리한 정답 라벨

8. 정리 규칙

다운로드한 파일을 그대로 모델에 넣기보다, 아래 규칙으로 정리한 뒤 사용하세요.

seq_id 통일
FASTA header, metadata, label TSV의 seq_id가 같아야 합니다.
날짜 정리
collection_date와 year를 꼭 만듭니다.
중복 제거
같은 strain/accession이 여러 번 있으면 하나만 남깁니다.
짧은 서열 제거
HA1보다 너무 짧거나 X가 많은 서열은 제외합니다.
출처 기록
NCBI, GISAID, 논문 부록 등 source를 metadata에 남깁니다.
제한 데이터 분리
GISAID 파일은 절대 git에 올리지 않습니다.

9. 코드로 검증하기

정리한 protein FASTA, metadata TSV, label TSV가 준비되면 기존 코드로 검증합니다.

protein manifest 만들기
PYTHONPATH=projects/influenza_protein_dl/src \
python projects/influenza_protein_dl/src/prepare_protein_manifest.py \
  --input data/private/processed/h3n2_ha1_proteins.fasta \
  --out analysis_results/influenza_protein_dl/h3n2_manifest.tsv
metadata/label 검증
PYTHONPATH=projects/influenza_protein_dl/src \
python projects/influenza_protein_dl/src/validate_model_inputs.py \
  --manifest analysis_results/influenza_protein_dl/h3n2_manifest.tsv \
  --metadata data/private/processed/h3n2_metadata.tsv \
  --labels data/private/labels/h3n2_antigenic_labels.tsv
