Influmatics Web Handoff

이 문서는 Influmatics H3N2 HA 분석 코드를 웹페이지/서버로 옮겨 구현할 친구와, 그 친구가 사용할 Codex가 같은 맥락에서 바로 이어 작업할 수 있도록 만든 인수인계 문서입니다.

기준일: 2026-06-23 · 기준 branch: JM · repository: https://github.com/ssy2205/influmatics.git

핵심 파일은 legacy/h3n2_ha_analysis.py입니다. 현재 코드는 교육/연구용 후향 분석에 한정되어 있으며, 새 변이 설계나 감염성/전파력/병원성/면역회피/내성 향상 추천 기능을 포함하지 않습니다.

1. 지금까지 구현된 것

분석 엔진

FASTA 입력을 받아 H3N2 HA 서열을 분석하고, clade assignment, antigenic site mutation, vaccine similarity, antiviral marker placeholder, phylogenetic tree 결과를 생성합니다.

Python CLI Biopython matplotlib

Tree pipeline

IQ-TREE로 ML tree를 만들고, TreeTime으로 시간축 tree를 만든 뒤, PNG/Newick/manifest를 생성합니다. 날짜 metadata CSV는 name,date 형식을 우선 지원합니다.

IQ-TREE TreeTime time-scaled tree

Outlier handling

TreeTime temporal outlier를 반복 제거하고 다시 IQ-TREE/TreeTime을 실행하는 기능을 추가했습니다. strain year와 collection date가 크게 충돌하는 metadata도 tree 입력 전에 제거합니다.

temporal outlier metadata conflict

Tree visualization

발표용에 가까운 figtree 스타일 PNG를 만들도록 개선했습니다. 최신 관측 tip으로 이어지는 backbone을 추정해 강조하고, target/vaccine marker와 clade bracket을 표시합니다.

backbone target marker vaccine marker
최근 로컬 실행 결과 기준으로 tree_display_tips=836, tree_date_metadata_rows=594, tree_date_metadata_matched=345, treetime_outliers_detected_final=0이었습니다.

3. 개발 환경 설치

권장 준비물은 Git, Python 3.10 이상, VS Code 또는 Cursor, 그리고 IQ-TREE 2입니다.

Python 가상환경

cd C:\dev\influmatics
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev,bio,web]"
python -m pip install numpy matplotlib biopython treetime

Python 3.11 또는 3.12를 추천합니다. 현재 로컬에서는 Python 3.13도 사용했지만, 다른 패키지 호환성을 생각하면 3.11/3.12가 더 무난합니다.

IQ-TREE

IQ-TREE는 repo에 포함하지 않습니다. 친구 PC에서 IQ-TREE 2 Windows binary를 설치한 뒤, 다음 둘 중 하나로 연결하면 됩니다. 

# 방법 A: PATH에 iqtree2.exe 추가 후 그냥 실행
iqtree2 -version

# 방법 B: repo 내부 로컬 도구 폴더에 두고 CLI 옵션으로 지정
mkdir .tools
# .tools\iqtree2.exe 위치에 실행 파일을 둔다
.\.tools\iqtree2.exe -version

TreeTime

TreeTime은 Python 패키지로 설치합니다. 설치 후 아래 명령으로 확인합니다. 

treetime --help
python -c "import treetime; print('treetime ok')"

Nextclade

현재 안정적인 운영 방식은 Nextclade Web/CLI 결과 TSV를 받아 --nextclade-results로 넘기는 것입니다. 서버 MVP에서는 Nextclade 자체 실행보다 결과 파일 업로드를 먼저 지원하는 편이 안전합니다.

4. 필요한 입력 파일

입력 형식 서버 UI에서의 의미 비고
target FASTA 사용자가 분석하려는 target sequence target 날짜가 header에 없으면 --target-date 필요
reference FASTA H3 numbering/projection 기준 서열 현재 legacy script에서 필수
background FASTA 공개 과거 H3N2 HA background sequences 데이터 정책상 GitHub에 커밋하지 말 것
vaccine FASTA 백신주/비교주 서열 tree marker와 vaccine similarity에 사용
tree_date_metadata CSV/TSV TreeTime 날짜 metadata name,date 컬럼 권장
nextclade_results TSV/CSV/JSON Nextclade clade assignment MVP에서는 업로드 파일로 받는 것을 추천
tree_outlier_file CSV/TXT tree에서 미리 제외할 outlier 목록 선택값. 이전 run의 outlier CSV 재사용 가능
공개 데이터라도 재배포 조건을 확인해야 합니다. 특히 GISAID 유래 원본 FASTA/metadata는 repo에 커밋하지 말고, 로컬 파일 또는 기관 내부 공유 방식으로 다루세요.

5. 현재 분석 CLI의 표준 실행 명령

서버는 처음에는 Python 함수를 직접 import하기보다 subprocess로 아래 CLI를 호출하는 구조가 가장 단순하고 안전합니다. 실제 서버에서는 <run_dir> 아래에 업로드 파일을 저장한 뒤 그 경로를 넣으면 됩니다. 

python legacy\h3n2_ha_analysis.py ^
  --target "<run_dir>\target.fasta" ^
  --reference "<run_dir>\reference.fasta" ^
  --background "<run_dir>\background.fasta" ^
  --vaccine "<run_dir>\vaccine.fasta" ^
  --outdir "<run_dir>\results" ^
  --tree-method iqtree-treetime ^
  --tree-plot-style figtree ^
  --tree-display-max-tips 0 ^
  --treetime-remove-outliers ^
  --treetime-outlier-max-passes 6 ^
  --tree-date-metadata "<run_dir>\tree_dates.csv" ^
  --target-date 2023 ^
  --iqtree-model GTR+G ^
  --iqtree-threads AUTO ^
  --iqtree-fast ^
  --clade-method nextclade ^
  --nextclade-results "<run_dir>\nextclade_results.tsv"

IQ-TREE가 PATH에 없으면 --iqtree-exe "C:\dev\influmatics\.tools\iqtree2.exe"를 추가하세요. TreeTime도 PATH에서 찾지 못하면 --treetime-exe 옵션을 사용할 수 있습니다.

7. 서버 구현 권장 구조

MVP는 FastAPI + subprocess + local run directory 구조를 추천합니다. 분석 시간이 길기 때문에 HTTP 요청 하나 안에서 끝까지 기다리게 하지 말고, background job으로 돌리는 구조가 좋습니다.

권장 API

Endpoint 역할 응답
POST /analyses 파일 업로드와 옵션을 받아 run 생성 { "run_id": "...", "status": "queued" }
GET /analyses/{run_id}/status 진행 상태와 로그 tail 조회 queued | running | completed | failed | cancelled
GET /analyses/{run_id}/results run_manifest.json 파싱 결과 반환 counts, outputs, warnings
GET /analyses/{run_id}/files/{name} PNG/CSV/Newick/HTML 다운로드 또는 미리보기 static file response
POST /analyses/{run_id}/cancel IQ-TREE/TreeTime 장기 실행 중단 { "status": "cancelled" }

서버 폴더 예시

web/
  server/
    app.py
    analysis_runner.py
    schemas.py
  frontend/
    package.json
    src/
  runs/
    20260623-abc123/
      inputs/
      results/
      run.log

subprocess 실행 개념

cmd = [
    sys.executable,
    "legacy/h3n2_ha_analysis.py",
    "--target", str(inputs / "target.fasta"),
    "--reference", str(inputs / "reference.fasta"),
    "--background", str(inputs / "background.fasta"),
    "--vaccine", str(inputs / "vaccine.fasta"),
    "--outdir", str(results),
    "--tree-method", "iqtree-treetime",
    "--tree-plot-style", "figtree",
    "--tree-display-max-tips", "0",
    "--treetime-remove-outliers",
    "--treetime-outlier-max-passes", "6",
    "--tree-date-metadata", str(inputs / "tree_dates.csv"),
    "--target-date", target_date,
    "--iqtree-model", "GTR+G",
    "--iqtree-threads", "AUTO",
    "--iqtree-fast",
    "--clade-method", "nextclade",
    "--nextclade-results", str(inputs / "nextclade_results.tsv"),
]

process = subprocess.Popen(
    cmd,
    cwd=repo_root,
    stdout=log_file,
    stderr=subprocess.STDOUT,
    text=True,
)

8. 프론트엔드 화면 구성

처음 화면부터 landing page처럼 만들지 말고, 실제 분석 워크플로우가 바로 보이게 구성하는 것이 좋습니다.

  1. Upload: target/reference/background/vaccine/date metadata/Nextclade result 업로드
  2. Options: TreeTime 사용, outlier 제거, target date, IQ-TREE fast mode
  3. Run: 실행 버튼, 현재 단계, 로그 tail, cancel 버튼
  4. Summary: manifest counts, 날짜 매칭 수, outlier 수, warnings
  5. Tree: phylogenetic_tree.png 확대/다운로드, Newick 다운로드
  6. Clade: clade table, clade count chart
  7. Antigenic: vaccine similarity table, cartography image
  8. QC/Outliers: metadata conflict, TreeTime outlier CSV table
  9. Files: 모든 결과 파일 다운로드
MVP에서는 tree를 interactive하게 다시 구현하지 말고, 우선 현재 PNG를 정확히 보여주는 것이 좋습니다. interactive tree는 Newick 기반으로 2차 개발에서 붙이면 됩니다.

9. 친구의 Codex에게 줄 시작 프롬프트

아래 문단을 그대로 친구의 Codex 첫 메시지로 넣으면 됩니다.

나는 Influmatics 프로젝트를 이어받아 웹 프론트엔드와 서버를 구축하려고 한다.
먼저 README.md, docs/web_handoff.html, legacy/h3n2_ha_analysis.py를 읽고 현재 분석 CLI를 이해해줘.

목표는 기존 Python 분석 코드를 바꾸기보다, FastAPI 또는 유사한 백엔드에서 subprocess로 실행하고
React/Vite 또는 Next.js 프론트엔드에서 파일 업로드, 실행 상태, 결과 대시보드를 제공하는 것이다.

안전 범위는 공개 과거 influenza A/H3N2 HA 서열의 후향 분석과 교육용 시각화다.
새로운 변이를 설계하거나 감염성/전파력/병원성/면역회피/내성을 높이는 변이를 추천/생성/순위화하지 않는다.
wet-lab protocol, synthesis, reverse genetics, virus rescue 내용도 포함하지 않는다.

우선 할 일:
1. docs/web_handoff.html의 API 설계를 기준으로 백엔드 skeleton을 제안해줘.
2. run마다 inputs/results/run.log 폴더를 만드는 job runner를 구현해줘.
3. legacy/h3n2_ha_analysis.py CLI를 subprocess로 실행하고 run_manifest.json을 파싱해줘.
4. 프론트엔드는 Upload, Run Status, Summary, Tree, Clade, Antigenic, QC/Outliers, Files 탭으로 구성해줘.
5. 현재 분석 결과 파일명을 바꾸지 말고 그대로 서빙해줘.

11. 안전 범위와 금지 범위

이 프로젝트는 공중보건 감시와 학습 목적의 공개 과거 데이터 기반 후향 분석에 한정합니다. 웹서비스에서도 아래 범위를 유지해야 합니다.

  • 허용: 공개 과거 서열의 clade, tree, vaccine similarity, known marker annotation, metadata visualization
  • 허용: published antigenic site 기반의 관찰 변이 설명
  • 허용: 과거 관찰 데이터의 표현학습/분류/추세 분석 연구 질문
  • 금지: 새 변이 설계, 생성, 추천, ranking
  • 금지: 감염성, 전파력, 병원성, 면역회피, 항바이러스제 내성 향상을 목표로 한 분석 기능
  • 금지: 배양, 합성, reverse genetics, virus rescue, wet-lab protocol 안내
