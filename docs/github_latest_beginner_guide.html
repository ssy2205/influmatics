2. 사용법을 외우는 한 줄 공식

처음에는 기능 이름을 다 외우려고 하지 말고, 이 다섯 단어만 외우면 됩니다.

가져오기 켜기 넣기 읽기 저장하기

1. 가져오기GitHub 최신 코드를 받습니다.
2. 켜기Python 가상환경과 웹 앱을 켭니다.
3. 넣기분석할 FASTA 파일과 날짜를 넣습니다.
4. 읽기QC, tree, clade, antigenic 결과를 봅니다.
5. 저장하기CSV, PNG, HTML 결과 파일을 내려받습니다.
핵심은 간단합니다. Influmatics는 바이러스 서열 파일을 넣으면, 변이와 계통/항원 관련 결과를 표와 그림으로 돌려주는 프로그램입니다.

3. 시작하기 전에: 지금은 pull 전에 조심

원격 GitHub에 새 커밋이 많지만, 로컬에는 아직 추적되지 않은 문서 파일이 있습니다. 바로 git pull을 하면 충돌은 없을 수도 있지만, 초보자 입장에서는 먼저 현재 파일을 확인하고 진행하는 편이 안전합니다. 

cd /Users/shiftyellow/Documents/project-local/influmatics_project/influmatics_code
git status --short --branch

최신 GitHub 코드를 실제로 로컬에 반영하려면, 작업 중인 파일을 정리한 뒤 아래 명령을 실행합니다.

git pull --ff-only
이 문서는 원격 GitHub 내용을 확인해서 작성했지만, 실제 로컬 코드 파일은 아직 자동으로 pull하지 않았습니다. 즉, 최신 웹 기능을 바로 실행하려면 먼저 최신 커밋을 로컬에 반영해야 합니다.

4. 최신 웹 앱 사용법: 가장 쉬운 길

최신 GitHub 방향은 브라우저에서 쓰는 분석 화면입니다. 기억할 입력은 세 가지입니다. Target FASTA, collection date, background preset.

입력초보자식 설명예시
Target FASTA분석하고 싶은 바이러스 서열 파일my_sample.fasta
Collection date그 바이러스를 채취한 날짜2024-01-20 또는 2024
Background preset비교용 과거 바이러스 묶음H3N2 HA demo reference background

최신 React/FastAPI 웹 앱을 로컬에서 켜는 개발자식 방법

이 방법은 GitHub 최신 커밋을 pull한 뒤 사용하는 흐름입니다.

새 터미널을 하나 더 열고 프론트엔드를 켭니다.

npm install
npm run dev

브라우저에서 http://127.0.0.1:5173을 열면 됩니다.

웹 화면에서 누르는 순서

  1. Upload 화면에서 Target FASTA를 올립니다.
  2. Collection date에 날짜를 씁니다. TreeTime을 쓰려면 날짜가 중요합니다.
  3. Background preset을 고릅니다. 데모 preset은 교육용이라 연구용으로는 충분하지 않습니다.
  4. Tree method는 최신 기본값인 IQ-TREE + TreeTime을 먼저 시도합니다.
  5. Start analysis를 눌러 실행합니다.
  6. 완료되면 Tree, Antigenic, Variability, Files 탭에서 결과를 확인합니다.
Codon variability는 과거 공개 서열의 관찰 요약입니다. 새 변이를 설계하거나, 전파력/면역회피/병원성을 높이는 추천 기능으로 해석하면 안 됩니다.

5. 명령어 사용법: 웹이 어려울 때의 기본기

명령어는 길어 보여도 구조는 같습니다. influmatics + 하고 싶은 일 + 입력 파일 + 결과 파일입니다.

1단계: FASTA 품질 검사

influmatics qc samples.fasta --out results/qc_summary.tsv

서열이 너무 짧거나 이상한 글자가 많은지 확인합니다.

2단계: 서열 정렬

influmatics align samples.fasta --out results/aligned.fasta --threads 4

여러 바이러스 서열을 같은 위치끼리 비교할 수 있도록 줄 맞춤합니다. MAFFT가 필요합니다.

3단계: 변이표 만들기

influmatics mutations results/aligned.fasta --reference-id reference --out results/mutations.tsv

기준 서열과 비교해 어느 위치가 바뀌었는지 표로 만듭니다.

4단계: 아미노산 변이표 만들기

influmatics translate \
  --alignment results/aligned.fasta \
  --reference-id reference \
  --cds-start 1 \
  --out results/aa_mutations.tsv

항원 부위와 약 내성 표는 보통 아미노산 좌표를 보기 때문에 이 단계가 중요합니다.

5단계: 항원 부위와 약 내성 스캔

influmatics antigenic results/aa_mutations.tsv \
  --sites data/markers/antigenic_sites_h3n2.json \
  --out results/antigenic_hits.tsv

influmatics resistance results/aa_mutations.tsv \
  --markers data/markers/antiviral_markers.tsv \
  --out results/resistance_hits.tsv

결과 TSV에 줄이 나오면, 알려진 중요한 위치에서 변이가 발견된 것입니다.

6. 결과를 읽는 쉬운 기준

결과보는 법초보자 해석
qc_summary.tsvpass_qc가 true인지 확인분석에 넣어도 되는 서열인지 보는 건강검진
phylogenetic_tree.newick, tree 그림target이 어느 배경 서열 근처에 있는지 확인내 샘플이 어떤 계통과 가까운지 보는 지도
clades.tsvclade/subclade 열 확인바이러스 족보 이름
antigenic_hits.tsv변이와 antigenic site 확인면역 인식에 중요한 자리에서 바뀌었는지
resistance_hits.tsvdrug class와 marker 확인약 내성으로 알려진 자리가 바뀌었는지
codon_variability.png변화가 많이 관찰된 과거 위치 확인교육용 관찰 요약, 예측 아님
외울 문장: QC는 입력 검사, Tree는 관계 지도, Clade는 족보 이름, Antigenic은 면역 관련 자리, Resistance는 약 내성 자리입니다.

7. 용어 사전

단어뜻
FASTA바이러스 유전자 글자를 담은 텍스트 파일 형식
Target내가 분석하려는 샘플
Background비교 대상이 되는 과거/참고 서열 묶음
Reference번호를 매길 때 기준으로 삼는 대표 서열
Clade비슷한 바이러스끼리 묶은 계통 이름
TreeTime수집 날짜를 이용해 시간축이 있는 계통수를 만드는 도구
IQ-TREE서열 차이를 바탕으로 계통수를 만드는 도구
Antigenic site면역계가 바이러스를 알아보는 데 중요한 위치
Codon variability과거 서열에서 코돈 변화가 얼마나 관찰되었는지 보는 교육용 요약
