Influmatics legacy H3N2 HA pipeline

Codex와 함께 진행한 작업 정리

작성일: 2026-06-23 · 대상 브랜치: JM

이 문서는 공개 과거 인플루엔자 A/H3N2 HA 서열을 이용한 후향적 교육/연구용 분석 대시보드 프로토타입에서, Codex가 코드에 반영한 기능과 실행 결과를 사람이 읽기 쉽게 정리한 것이다.

1. 안전 범위

현재 코드는 공개 또는 로컬 입력 FASTA를 기준으로 이미 관찰된 서열을 정렬, 주석, 분류, 시각화하는 후향적 분석 도구이다. 새로운 바이러스 서열 설계, 감염성·전파력·병원성·면역회피·항바이러스제 내성 증가 변이 추천, 실험 프로토콜, 배양, 합성, reverse genetics, virus rescue 기능은 넣지 않았다.

2. 지금까지 반영한 핵심 기능

입력 처리 target, reference, background, vaccine FASTA를 읽고, nucleotide 입력은 six-frame 번역과 reference protein alignment를 통해 HA 좌표계에 맞춘다.
클레이드 분류 --clade-method nextclade와 --nextclade-dataset을 지원한다. Nextclade CLI가 있으면 실제 Nextclade 결과를 우선 사용하고, 필요 시 규칙 기반 fallback을 사용할 수 있다.
항원부위 비교 사용자가 지정한 H3 antigenic site 집합과 Koel 7개 핵심 위치 가중치를 이용해 target-vaccine antigenic distance와 site mutation table을 만든다.
항바이러스제 관련 주석 HA 기반 marker table 형태로 변이를 annotation한다. NA 내성 예측처럼 다른 유전자 정보가 필요한 영역은 안전하게 분리되어 있다.
Full background tree MAX_TREE_SEQUENCES = 0로 기본 축약 제한을 제거했다. 실행 시 --max-tree-sequences 0이면 background를 샘플링하지 않고 사용한다.
IQ-TREE + TreeTime --tree-method iqtree-treetime을 추가했다. projected codon nucleotide alignment를 만들고 IQ-TREE ML tree를 계산한 뒤 TreeTime으로 time-scaled tree를 만든다.
TreeTime outlier 제거 --treetime-remove-outliers를 추가했다. 1차 TreeTime의 outliers.tsv를 읽어 temporal outlier를 제거하고 IQ-TREE/TreeTime을 한 번 더 실행한다.
트리 시각화 레퍼런스 PPT처럼 흰 배경, 얇은 검은 가지, 연도축, 파란 target marker, 빨간 vaccine marker 중심의 figtree 스타일을 추가했다.
검증 기록 실행 조건과 출력 파일을 run_manifest.json에 남기고, 주요 CSV/PNG/HTML 산출물을 results_latest에 생성한다.

3. 최종 실행 예시

python h3n2_ha_analysis.py ^
  --target h3n2_testdata\target.fasta ^
  --reference h3n2_testdata\reference.fasta ^
  --background h3n2_testdata\background.fasta ^
  --vaccine h3n2_testdata\vaccine.fasta ^
  --outdir h3n2_testdata\results_latest ^
  --max-tree-sequences 0 ^
  --tree-method iqtree-treetime ^
  --treetime-remove-outliers ^
  --tree-plot-style figtree ^
  --target-date 2023 ^
  --iqtree-model GTR+G ^
  --iqtree-threads AUTO ^
  --min-identity 0 ^
  --clade-method nextclade ^
  --nextclade-dataset ..\data\nextclade\h3n2_ha_epi1857216

5. 레퍼런스 PPT 반영 내용

  • 처음 잘못 전달된 PPT 대신 20260116 phylogenetic tree.pptx를 기준으로 삼았다.
  • 레퍼런스 이미지는 FigTree류 time tree 형태였다: 흰 배경, 얇은 검은 branch, 하단 calendar-year axis, 파란 점과 빨간 삼각형 marker.
  • 기존 산출물은 너무 dashboard/legend 중심이라, --tree-plot-style figtree를 기본으로 추가했다.
  • 오래된 reference/vaccine 서열이 x축을 과하게 늘리지 않도록 표시용 x축 범위를 관찰 데이터 중심으로 자동 조정했다.
  • TreeTime 내부 노드 시간을 branch length 기반 calendar year로 보정하고, terminal ordering도 calendar year 중심으로 정렬했다.

6. 주요 파일

legacy/h3n2_ha_analysis.py 현재 H3N2 HA 단일 스크립트 분석 파이프라인의 핵심 구현.
legacy/original_scripts/influenza_a_analysis.py 초기 prototype script. 입력 normalization/reference-frame alignment 개선이 반영되어 있다.
docs/codex_work_summary.html 지금까지의 Codex 작업 내용과 실행 결과를 설명하는 문서.

7. 남은 개선 후보

  • full background 원본 tree와 발표용 sampled/date-window tree를 별도 산출물로 분리하기.
  • Nextclade dataset 다운로드/검증 명령을 문서화하거나 자동 검사하기.
  • legacy script의 대형 함수들을 package module로 점진적으로 분리하기.
  • HTML report에 TreeTime outlier table과 tree rendering 설정을 더 명확히 표시하기.

8. codex/fix/lint-and-test-hardening 브랜치 반영

첫 번째 push 후 GitHub의 codex/fix/lint-and-test-hardening 브랜치를 가져와 현재 JM 브랜치에 선택적으로 반영했다. 해당 브랜치는 legacy/h3n2_ha_analysis.py를 삭제하는 방향도 포함하고 있었기 때문에, 우리가 만든 H3N2 IQ-TREE/TreeTime 작업을 보존하기 위해 통째 merge하지 않았다.

일부러 제외한 것 legacy/h3n2_ha_analysis.py 삭제 변경은 반영하지 않았다. 이 파일은 현재 full background, Nextclade, IQ-TREE, TreeTime, outlier 제거, FigTree 스타일 렌더링이 들어간 핵심 프로토타입이기 때문이다.
가져온 코드 influmatics/validation.py influmatics/translate.py influmatics/web.py influmatics/cli.py alignment/antigenic/clade/mutations/numbering/qc/report/resistance
입력 검증, NT-to-AA translation bridge, Streamlit web launcher, Nextclade AA mutation parsing, marker scanning, report generation, numbering map 관련 hardening을 package 코드에 반영했다.
가져온 테스트 alignment, antigenic site, clade, curated marker data, mutation parsing, numbering, resistance, translate, web launcher 테스트를 추가했다. 기존 test_io_qc_mutations.py도 브랜치 기준으로 보강했다.
가져온 CI/협업 파일 .github/workflows/tests.yml, pull request template, git workflow guide, contribution guide 업데이트를 반영했다. GitHub Actions에서는 package 설치, pytest, compileall을 수행한다.
가져온 문서 docs/usage_guide.html, docs/easy_start.html, docs/deep_learning_training_guide.html, docs/project_summary.html, docs/marker_curation_report.md를 추가해 초심자용 사용법, 연구 기획, 딥러닝 계획, marker curaton 근거를 보강했다.
데이터 보강 H1N1 antigenic site 예시, H3N2 antigenic site 정의 업데이트, antiviral marker table, numbering example, redistributable reference FASTA 예시를 반영했다.

9. 브랜치 반영 후 추가 수정

  • ruff가 legacy 코드에서 잡은 lambda assignment, unused variable/import, semicolon 스타일 문제를 수정했다.
  • build_fast_upgma_tree_png() 안에 남아 있던 미정의 xlim 참조를 제거하고, target label 위치 계산을 xmax 기준으로 바꾸었다.
  • 로컬 외부 도구, Nextclade dataset, handoff, 작업 폴더, 실행 로그가 실수로 Git에 올라가지 않도록 .gitignore를 정리했다.
