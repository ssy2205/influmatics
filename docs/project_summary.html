Influmatics

계절성 인플루엔자 바이러스의 항원 변이를 분석하는 프로그램. 서열을 넣으면 품질검사부터 변이 탐지, 항원 부위·약물 내성 스캔, 웹 화면 분석까지 한 번에.

🧬 무슨 기능이 있나요

분석 흐름 한눈에

① 입력 검사 (QC)서열 길이·이상 글자·갭 확인, 합격 여부 표시
② 정렬 (MAFFT)여러 서열을 기준에 맞춰 정렬
③ 변이표 만들기기준 대비 염기/아미노산 변이 추출 (치환·삽입·결손)
④ Nextclade clade유행 계통 분류 + 아미노산 변이 자동 추출
⑤ 항원 부위 / 내성 스캔면역 회피·약물 내성 자리 자동 표시
⑥ 리포트 / 웹 화면HTML 보고서, 브라우저 분석 앱
🩺

품질 검사 (QC)

FASTA를 넣으면 길이, 모호 염기, 갭, 잘못된 글자를 검사해 합격/불합격을 표로 보여줍니다.

🧷

정렬 · 변이 탐지

MAFFT 정렬 후 기준 서열과 비교해 변이를 호출. 다중 염기 삽입/결손을 하나로 묶고, 모호 염기(N)는 따로 표시합니다.

🔤

아미노산 번역 · 번호 매김

염기 변이를 아미노산 변이로 번역(동의/비동의/넌센스/프레임시프트 구분)하고, 표준 번호 체계로 매핑합니다.

🧭

Nextclade 연동

clade(유행 계통)를 붙이고, aaSubstitutions를 스캐너가 바로 쓰는 아미노산 변이표로 변환합니다.

🎯

항원 부위 스캔

변이가 면역 회피 자리에 있는지 확인. H3N2(부위 A·B)와 H1N1(Sa·Sb·Ca1·Ca2·Cb) 모두 지원.

💊

항바이러스 내성 스캔

약물 내성 변이 탐지. 뉴라미니다제 억제제(NAI)·아만타딘 마커를 큐레이션해 두었습니다.

H275YS31NE119VN295S

🖥️

웹 앱 (Streamlit)

명령어 한 줄(influmatics web)로 브라우저에서 분석. QC 탭과 스캔 탭, 결과 다운로드까지.

🛠️ 이번에 한 작업

✓
코드 정리 · 테스트 강화미사용 import 제거(ruff clean), MAFFT 실바이너리 통합 테스트, 변이 파싱·번호 매김 견고화 및 회귀 테스트 추가
✓
마커 데이터 큐레이션보고서 근거로 H3N2·H1N1 항원 부위 JSON, 항바이러스 마커 TSV 작성 (이전엔 빈 placeholder)
✓
Nextclade 아미노산 다리clade 출력의 AA 변이를 파싱해 스캐너 입력으로 연결, clade --aa-out 옵션 추가
✓
Streamlit 웹앱 실제 연결입력만 받던 껍데기를 실제 실행으로 연결, influmatics web 런처 추가, 스크립트 실행 임포트 버그 수정
✓
