Beginner Guide

인플루엔자 서열 분석과 단백질 딥러닝 파이프라인 사용법

이 문서는 처음 사용하는 사람을 위해 Influmatics의 설치, FASTA 분석, 항원 부위/내성 마커 스캔, 딥러닝 baseline 실험을 단계별로 설명합니다. 모든 명령은 저장소 루트인 influmatics_code 폴더에서 실행합니다.

1. 입력 준비FASTA, metadata, label TSV를 준비합니다.
2. QC서열 길이, ambiguous base, gap, invalid 문자 확인.
3. 변이 분석alignment, mutation, AA translation 또는 Nextclade 사용.
4. 마커 스캔항원 부위와 항바이러스 내성 marker를 검사합니다.
5. 모델 실험protein manifest, dataset, split, ridge baseline 학습.

1. 시작 전 준비

이 프로젝트는 두 갈래로 사용할 수 있습니다. 하나는 인플루엔자 서열을 QC하고 변이/항원 부위/내성 marker를 확인하는 기본 분석이고, 다른 하나는 HA1 단백질 서열로 항원성 좌표 또는 novelty score를 예측하는 딥러닝 실험입니다.

데이터 주의: GISAID처럼 재배포 제한이 있는 FASTA와 metadata는 저장소에 커밋하지 마세요. 개인 분석용 파일은 data/private/ 또는 저장소 밖에 두는 것을 권장합니다.

처음 실행 위치 확인

터미널에서 아래 폴더로 이동한 뒤 명령을 실행합니다.

저장소 루트로 이동
cd /Users/shiftyellow/Documents/project-local/influmatics_project/influmatics_code

2. 설치

Python 가상환경을 만들고 개발 모드로 패키지를 설치합니다. 한 번만 해두면 influmatics 명령을 바로 사용할 수 있습니다.

Python 환경 만들기
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
외부 도구: alignment에는 mafft, clade 분석에는 nextclade가 필요합니다. QC, TSV 검증, 딥러닝 toy baseline은 이 도구 없이도 실행할 수 있습니다.

3. 기본 서열 분석

가장 먼저 할 일은 FASTA 파일이 분석 가능한 상태인지 확인하는 것입니다. 공개 reference 예시는 data/references/에 들어 있습니다.

3-1. FASTA QC

H1N1 reference QC 예시
influmatics qc data/references/FJ966974.1_H1N1pdm09_HA.fasta \
  --out results/qc_h1n1.tsv \
  --min-length 1000

3-2. MAFFT alignment

여러 서열을 비교하려면 먼저 정렬된 FASTA를 만들어야 합니다. 입력 FASTA에는 reference와 sample 서열이 함께 있어야 합니다.

alignment
influmatics align samples.fasta \
  --out results/aligned.fasta \
  --threads 4

3-3. nucleotide mutation table

mutation table
influmatics mutations results/aligned.fasta \
  --reference-id reference \
  --out results/mutations.tsv

3-4. amino-acid mutation table

항원 부위와 내성 marker는 아미노산 좌표를 기준으로 합니다. 그래서 nucleotide mutation table만으로는 부족하고, AA mutation table을 만들어야 합니다.

AA translation
influmatics translate \
  --alignment results/aligned.fasta \
  --reference-id reference \
  --cds-start 1 \
  --out results/aa_mutations.tsv

4. 항원 부위와 항바이러스 내성 스캔

results/aa_mutations.tsv처럼 coordinate_space=aa가 들어 있는 mutation table을 사용합니다.

H3N2 항원 부위

H3 numbering 기준 항원 부위 A/B 핵심 위치를 검사합니다.

antigenic scan
influmatics antigenic results/aa_mutations.tsv \
  --sites data/markers/antigenic_sites_h3n2.json \
  --out results/antigenic_hits.tsv

항바이러스 내성

NA와 M2 marker를 검사합니다. 필요하면 --gene과 --subtype으로 좁힙니다.

resistance scan
influmatics resistance results/aa_mutations.tsv \
  --markers data/markers/antiviral_markers.tsv \
  --out results/resistance_hits.tsv

5. Nextclade로 clade와 AA mutation 만들기

Nextclade를 설치했다면 clade assignment와 AA mutation TSV를 한 번에 만들 수 있습니다. 이 방식으로 만든 AA table도 antigenic/resistance scanner에 바로 넣을 수 있습니다.

Nextclade 분석
influmatics clade \
  --input-fasta samples.fasta \
  --dataset flu_h3n2_ha \
  --outdir results/nextclade \
  --out results/clades.tsv \
  --aa-out results/aa_mutations.tsv

6. 딥러닝 baseline 실험

딥러닝 프로젝트는 projects/influenza_protein_dl/에 있습니다. 실제 label이 아직 없어도 toy 예시로 전체 흐름을 확인할 수 있습니다.

6-1. protein FASTA에서 manifest 만들기

protein manifest
PYTHONPATH=projects/influenza_protein_dl/src \
python projects/influenza_protein_dl/src/prepare_protein_manifest.py \
  --input projects/influenza_protein_dl/examples/toy_ha1.fasta \
  --out analysis_results/influenza_protein_dl/toy_manifest.tsv

6-2. 입력 TSV 검증

input validation
PYTHONPATH=projects/influenza_protein_dl/src \
python projects/influenza_protein_dl/src/validate_model_inputs.py \
  --manifest analysis_results/influenza_protein_dl/toy_manifest.tsv \
  --metadata projects/influenza_protein_dl/examples/toy_metadata.tsv \
  --labels projects/influenza_protein_dl/examples/toy_labels.tsv

6-3. 학습용 dataset 만들기

dataset build
PYTHONPATH=projects/influenza_protein_dl/src \
python projects/influenza_protein_dl/src/build_coordinate_dataset.py \
  --manifest analysis_results/influenza_protein_dl/toy_manifest.tsv \
  --metadata projects/influenza_protein_dl/examples/toy_metadata.tsv \
  --labels projects/influenza_protein_dl/examples/toy_labels.tsv \
  --out analysis_results/influenza_protein_dl/toy_dataset.tsv

6-4. mutation feature를 dataset에 붙이기

AA mutation TSV가 있으면 항원 부위 변이 개수 같은 feature를 추가할 수 있습니다.

mutation features
PYTHONPATH=projects/influenza_protein_dl/src \
python projects/influenza_protein_dl/src/build_mutation_features.py \
  --aa-mutations projects/influenza_protein_dl/examples/toy_aa_mutations.tsv \
  --antigenic-sites projects/influenza_protein_dl/examples/toy_antigenic_sites.json \
  --out analysis_results/influenza_protein_dl/toy_mutation_features.tsv
dataset with mutation features
PYTHONPATH=projects/influenza_protein_dl/src \
python projects/influenza_protein_dl/src/build_coordinate_dataset.py \
  --manifest analysis_results/influenza_protein_dl/toy_manifest.tsv \
  --metadata projects/influenza_protein_dl/examples/toy_metadata.tsv \
  --labels projects/influenza_protein_dl/examples/toy_labels.tsv \
  --mutation-features analysis_results/influenza_protein_dl/toy_mutation_features.tsv \
  --out analysis_results/influenza_protein_dl/toy_dataset_with_mutations.tsv

6-5. ridge baseline 학습

baseline training
PYTHONPATH=projects/influenza_protein_dl/src \
python projects/influenza_protein_dl/src/train_ridge_baseline.py \
  --dataset analysis_results/influenza_protein_dl/toy_dataset_with_mutations.tsv \
  --outdir analysis_results/influenza_protein_dl/toy_ridge_with_mutations \
  --split-strategy temporal \
  --train-end-year 2021 \
  --valid-years 2022 \
  --test-start-year 2023

7. 결과 파일 읽기

파일 의미 처음 볼 컬럼
results/qc_h1n1.tsv 서열 QC 결과 pass_qc, fail_reasons, ambiguous_fraction
results/aa_mutations.tsv 아미노산 변이 테이블 mutation, position, coordinate_space
results/antigenic_hits.tsv 항원 부위에 걸린 변이 seq_id, mutation, site
analysis_results/.../metrics.json 모델 평가 지표 mae_mean, rmse_mean, split_counts
analysis_results/.../predictions.tsv 모델 예측값 target_antigenic_x, pred_antigenic_x

9. 문제 해결

문제 원인 해결
influmatics: command not found 가상환경이 꺼져 있거나 패키지가 설치되지 않음 source .venv/bin/activate 후 python -m pip install -e ".[dev]"
No module named influmatics 설치 없이 테스트를 실행함 PYTHONPATH=. pytest 또는 editable install 사용
coordinate_space 오류 AA scanner에 nucleotide mutation table을 넣음 influmatics translate 또는 influmatics clade --aa-out로 AA table 생성
MAFFT 또는 Nextclade 오류 외부 프로그램 미설치 또는 dataset 이름 문제 mafft --version, nextclade --version으로 설치 확인
모델 dataset row가 0개 manifest, metadata, labels의 seq_id가 서로 맞지 않음 세 파일의 seq_id 철자와 중복 여부 확인
